NaviMovie-Maker CHANGELOG
=========================

v0.2.1 - 音量正規化と出力名の改善
----------------------------------

追加:

- FFmpeg の ReplayGain を利用した「音量の正規化（dB）」を追加
- 89.0 dB 基準の目標音量指定を追加
- ピーク上限、許容差、最大増幅量の設定を追加
- 設定 JSON とプレイリストへ正規化方式と設定値を保存
- ReplayGain 解析中のキャンセルに対応

変更:

- 音声ゲイン正規化で、従来の Peak 方式と ReplayGain 方式を選択可能に変更
- 通常モードと Simple Mode で共通の正規化処理を使用
- 出力ファイル名の衝突判定を改善

修正:

- 実際には名前衝突がない変換結果にも、末尾へ識別子が付いていた問題を修正
- 同じ項目の管理済み成果物を再利用できる場合にも、別名候補が生成される可能性があった問題を修正


v0.2.0 - 再利用可能なプレイリストと処理結果管理
------------------------------------------------

追加・改善:

- 変換キュー、URL、ローカルファイル、主な処理設定を .nmm-playlist.json へ保存・再読込できる変換プレイリストを追加
- 新規、開く、保存、名前を付けて保存の標準コマンドと Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S を追加
- 初回保存後の上書き保存、dirty 表示、未保存変更の保存／保存しない／キャンセル確認を追加
- プレイリストごとに異なる出力フォルダを保存・復元できるように改善
- mpv を外部プロセスとして使用するプレイリスト再生と Ctrl+P を追加
- ローカルファイル、mpv/yt-dlp が解決可能な URL、追跡済み処理結果のキュー順再生に対応
- 全項目に有効な結果がある場合は結果を、それ以外では元データを選ぶ自動再生を追加
- mpv の標準出力／標準エラー、終了コード、実行パス、一時 M3U8 を使った失敗診断を追加
- URL 再生で yt-dlp のフルパスを script-opt へ渡さず、PATH 経由で検出させるよう修正
- プレイリスト項目の安定 ID と、ソース・処理モード・プロファイル・結果ファイル情報の永続化を追加
- 結果列に未処理、出力済み、連番未同期、出力なし、出力変更あり、要再処理、名前衝突を表示
- 有効な既存処理結果を検証し、再実行時の不要な処理を省略する機能を追加
- Download Only の完成ダウンロードを処理結果として追跡
- 所有者不明ファイルを上書きしない、ソース識別子に基づく決定論的な出力名衝突回避を追加
- キュー並べ替え後に追跡済み出力の先頭連番だけを二段階リネームで同期する機能を追加
- 旧形式 v1 プレイリストの読込と安定 ID 生成に対応

v0.1.1 - UI改善と配布文書更新
-----------------------------

改善:

- Simple Mode 表示時に、通常モードの不要な操作UIを隠すように改善
- Simple Mode と通常モードの操作領域を排他的に表示するように調整
- ログ表示エリアを初期状態で折りたたむように変更
- キューリストの状態表示を見やすく調整
- 処理中のキュー項目を Delete キーなどで削除できないように調整
- Simple Mode からキャンセル操作を行いやすいように改善
- 出力プリセットの表示/非表示設定と選択状態の保存・復元を改善
- iPad / Android タブレット向けプリセットの表示設定が意図せず復活する問題を修正
- ダウンロード説明と Windows SmartScreen / Smart App Control に関する注意書きを更新


v0.1.0 - 初回公開版
-------------------

NaviMovie-Maker の初回公開版です。

追加:

- 変換キューによる一括処理
- ローカルファイルのドラッグ＆ドロップ追加
- 対応サイト URL の情報取得
- yt-dlp による動画情報取得とダウンロード
- FFmpeg / ffprobe による動画・音声変換
- FFmpeg / ffprobe / yt-dlp の導入確認
- FFmpeg / yt-dlp の自動取得支援
- 車載ナビ向け MP4 プリセット
- USB/SD 対応 DVD プレイヤー向け MPG プリセット
- Android タブレット / iPad 向け MP4 プリセット
- HEVC などの高圧縮プリセット
- 音声抽出・音声変換プリセット
- Simple Mode
- 通常モードの処理種別
  - ダウンロードのみ
  - ダウンロードして変換
  - 変換のみ
  - ファイルコピー
- 進捗・ログ表示
- 出力フォルダ、表示プリセット、外部ツールパスなどの設定
