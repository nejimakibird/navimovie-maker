NaviMovie-Maker CHANGELOG
=========================

Unreleased
----------

追加:

- 変換キューと主な変換設定を保存・復元できるプレイリスト機能を追加
- .nmm-playlist.json 形式でローカルファイルと URL の変換ジョブを保存可能に
- 読み込み時に実行状態を待機状態へリセットし、見つからないローカルファイルを対象外として表示

v0.1.1 - UI改善と配布文書更新
-----------------------------

改善:

- Simple Mode 表示時に、通常モードの不要な操作UIを隠すように改善
- Simple Mode と通常モードの操作領域を排他的に表示するように調整
- ログ表示エリアを初期状態で折りたたむように変更
- キューリストの状態表示を見やすく調整
- 処理中のキュー項目を Delete キーなどで削除できないように調整
- Simple Mode からキャンセル操作を行いやすいように改善
- 出力プリセットの表示/非表示設定と選択状態の保存・復元を改善
- iPad / Android タブレット向けプリセットの表示設定が意図せず復活する問題を修正
- ダウンロード説明と Windows SmartScreen / Smart App Control に関する注意書きを更新


v0.1.0 - 初回公開版
-------------------

NaviMovie-Maker の初回公開版です。

追加:

- 変換キューによる一括処理
- ローカルファイルのドラッグ＆ドロップ追加
- 対応サイト URL の情報取得
- yt-dlp による動画情報取得とダウンロード
- FFmpeg / ffprobe による動画・音声変換
- FFmpeg / ffprobe / yt-dlp の導入確認
- FFmpeg / yt-dlp の自動取得支援
- 車載ナビ向け MP4 プリセット
- USB/SD 対応 DVD プレイヤー向け MPG プリセット
- Android タブレット / iPad 向け MP4 プリセット
- HEVC などの高圧縮プリセット
- 音声抽出・音声変換プリセット
- Simple Mode
- 通常モードの処理種別
  - ダウンロードのみ
  - ダウンロードして変換
  - 変換のみ
  - ファイルコピー
- 進捗・ログ表示
- 出力フォルダ、表示プリセット、外部ツールパスなどの設定
