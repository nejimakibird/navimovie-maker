# NaviMovie-Maker

## 1. NaviMovie-Maker とは

NaviMovie-Maker は、オンライン動画 URL やローカルの動画・音声ファイルを、カーナビ、USB/SD 対応 DVD プレーヤー、ローカル再生環境で扱いやすい形式へ準備するための Windows デスクトップアプリです。

現在のアプリは `Conversion Queue` を中心にしたワークフローです。動画 URL やローカルファイルをキューへ追加し、`動作モード`、`出力形式`、音声補正などを選んで、キューを上から順番に実行します。

オンライン動画の取得には `yt-dlp`、変換や音声処理には `FFmpeg` / `ffprobe` を使用します。NaviMovie-Maker には外部ツールの確認・自動取得サポートがありますが、これらのツール自体は NaviMovie-Maker とは別の外部ツールです。

Simple Mode は今後予定していますが、まだ実装されていません。この README は、現在実装されている通常のキュー操作を説明します。

## 2. 主な機能

- 検索語から YouTube の動画候補を取得
- 動画 URL を直接入力して候補を取得
- URL を入力欄または `Conversion Queue` へドラッグ＆ドロップ
- ローカル動画・音声ファイルをファイル選択またはドラッグ＆ドロップでキューへ追加
- キュー内の項目を `DLのみ`、`DL＋変換`、`変換のみ`、`ファイルコピー` の各モードで処理
- `Car Navi MP4`、`DVD Player MPG`、音声変換系プリセットによる変換
- アスペクト比の `比率維持＋余白` / `引き伸ばし` 選択
- `DL元を残す`、連番開始、音量持ち上げ、音量ノーマライズ設定
- キュー項目の並べ替え、削除、クリア、失敗分の再実行、キャンセル
- `Working Folder`、`Converted Folder`、`Temporary Folder`、`Local Video Folder` の設定
- 外部ツール確認、自動取得、tools フォルダ表示
- ログ表示とコピー

## 3. 必要な外部ツールと導入サポート

### yt-dlp

`yt-dlp.exe` は、オンライン動画 URL のメタデータ取得とダウンロードに使用します。検索、URL 読込、URL ドロップ後の情報取得、`DLのみ`、`DL＋変換` で必要になります。

対応サイトや取得可否は `yt-dlp` と対象サイト側の状態に依存します。サイト側の仕様変更、利用規約、地域制限、ログイン要否などにより取得できない場合があります。

### FFmpeg / ffprobe

`ffmpeg.exe` は動画・音声変換、音声抽出、音量補正、コピーではないメディア処理に使用します。`ffprobe.exe` は FFmpeg と同じ配布物に含まれることが多く、外部ツール確認の対象です。

変換モードや音声系プリセットを使う場合は FFmpeg が必要です。

### アプリ内の導入サポート

メニューの `ツール` から外部ツールを扱えます。

- `外部ツール確認`: 設定済みパス、アプリの `tools` フォルダ、`PATH` の順に `yt-dlp.exe`、`ffmpeg.exe`、`ffprobe.exe` を確認します。
- `外部ツールを自動取得`: `yt-dlp.exe` と FFmpeg essentials zip をダウンロードし、`yt-dlp.exe`、`ffmpeg.exe`、`ffprobe.exe` をアプリの `tools` フォルダへ配置します。
- `tools フォルダを開く`: アプリが外部ツールを置くフォルダを開きます。
- `設定`: 外部ツールの実行ファイルパスや取得 URL を手動指定できます。

外部ツールの探索順は次の通りです。

1. `設定` で指定したパス
2. アプリの `tools` フォルダ
3. Windows の `PATH`

## 4. 基本的な使い方

### URLを検索欄に入力

1. `動画ソース` で `検索` を選びます。
2. `検索語` にキーワードを入力します。
3. 必要に応じて `検索結果` の件数を選びます。
4. `URL読込` を押します。
5. 取得された候補から必要なものを選び、`選択項目をキューへ追加` で `Conversion Queue` へ追加します。

`URL指定` を選ぶと、検索語ではなく `動画URL` を直接入力できます。Enter キーでも `URL読込` を実行できます。

### URLをConversion Queueへドラッグ

HTTP / HTTPS の URL は `Conversion Queue` へ直接ドラッグできます。ドロップされた URL はキューに追加され、`yt-dlp` による動画情報取得が始まります。

情報取得中はタイトルが `読み込み中...` になり、状態は `情報取得中...` になります。取得に成功するとタイトルが更新されて `待機中` になります。取得に失敗した場合でも、フォールバックタイトル付きでキューに残り、`注意: 動画情報を取得できませんでした。処理時に再試行します。` と表示される場合があります。

現在の URL ドロップは通常操作向けに保守的です。YouTube の単体動画 URL や Shorts URL は標準の watch URL に正規化されます。一方、チャンネル、プレイリスト、radio、user など複数項目に展開される可能性がある URL は、対象外またはエラー扱いになる場合があります。

### ローカルファイルをキューへドラッグ

ローカルの動画・音声ファイルは `Conversion Queue` へドラッグ＆ドロップできます。ファイル選択ボタンから追加することもできます。

対応しているローカルファイル拡張子は次の通りです。

- 動画: `.mp4`, `.m4v`, `.mov`, `.avi`, `.mpg`, `.mpeg`, `.wmv`, `.mkv`, `.webm`
- 音声: `.wav`, `.mp3`, `.m4a`, `.aac`, `.flac`, `.ogg`, `.wma`

現在のバージョンでは、フォルダをドロップしても中身は再帰的に読み込みません。フォルダ、存在しないパス、未対応拡張子は、理由を確認できるように `対象外` のキュー項目として表示されます。

## 5. 動作モード

| 動作モード | URL | ローカルファイル | 主な用途 |
|---|---:|---:|---|
| DLのみ | 対象 | 対象外 | URLから元ファイルを取得 |
| DL＋変換 | 対象 | 対象 | URLから取得して指定形式へ変換。キュー内の対応ローカルファイルも変換 |
| 変換のみ | 対象外 | 対象 | ローカル動画・音声ファイルを変換 |
| ファイルコピー | 対象外 | 対象 | ファイルを指定フォルダへコピー |

画面上のモード名は次のラベルです。

- `ダウンロードのみ`: 内部モード `Download Only`
- `ダウンロードして変換`: 内部モード `Download & Convert`
- `変換のみ`: 内部モード `Convert Only`
- `ファイルコピー`: 内部モード `Copy Files`

選択中の動作モードで処理できない項目は、キュー上で `対象外` として表示されます。たとえば `DLのみ` ではローカルファイルが対象外になり、`変換のみ` と `ファイルコピー` では URL が対象外になります。

## 6. キューの状態表示

`Conversion Queue` の `状態` 列には、状態テキストと進捗バーが表示されます。処理中はキュー全体の進捗もヘッダーや進捗表示に反映されます。

- `情報取得中...`: URLドロップ後、yt-dlpで動画情報を取得中
- `待機中`: 処理開始待ち
- `処理中`: ダウンロード、変換、コピーなどを実行中。進捗、速度、残り時間が取得できる場合は表示に反映されます
- `対象外`: 現在の動作モードでは処理できない項目、未対応ファイル、フォルダ、広すぎる URL など
- `注意`: メタデータ取得失敗など、処理可能だが確認が必要な項目
- `完了`: `Completed`、`Converted`、`Downloaded` など、処理が正常に終わった状態
- `失敗`: `Failed`、`Convert Failed` など、ダウンロード、変換、コピーに失敗した状態
- `Skipped`: キャンセル、モード不一致、前段失敗などによりスキップされた状態

失敗したキュー項目は `失敗分を再実行` で再実行できます。実行中のキューは `キャンセル` できます。

## 7. 出力先フォルダ

既定では、ユーザーの Videos フォルダ配下に `NaviMovie-Maker` 用のフォルダを作ります。

- `Working Folder`: `Videos\NaviMovie-Maker\work`
- `Temporary Folder`: `Videos\NaviMovie-Maker\temp`
- `Converted Folder`: `Videos\NaviMovie-Maker\converted`
- `Local Video Folder`: `Videos\NaviMovie-Maker\local`

`設定` の `フォルダ` タブで各フォルダを変更できます。設定保存時、存在しないフォルダは自動作成されます。

`Working Folder` は `DLのみ` の保存先や、`DL元を残す` を有効にした場合の元ファイル保存先として使われます。

`Converted Folder` は変換後ファイルやコピー先の既定フォルダです。メイン画面の `出力先...` から、そのセッションだけの出力先も選べます。

`Local Video Folder` はローカルファイル選択時の初期表示フォルダです。

`出力形式ごとにサブフォルダを作成` が有効な場合、プリセットやモードに応じたサブフォルダへ出力します。

## 8. 代表的なプリセット

表示する `出力形式` は `設定` の `出力形式` タブで変更できます。初期状態で表示される代表的なプリセットは次の通りです。

### Car Navi MP4

- `Car Navi MP4 - Current Compatibility`: 現在の互換性優先プリセット。MP4 / H.264 / AAC 系の出力です。
- `Car Navi MP4 - Standard`: 720x480 の標準候補です。
- `Car Navi MP4 - Small Size`: 640x360 の容量優先候補です。

### DVD Player MPG

- `Portable DVD Player MPG - Standard (MP2 audio)`: USB/SD 再生対応 DVD プレーヤー向けの `.mpg` ファイルを作る実用プリセットです。
- 追加で Small Size / High Quality 相当の MPG プリセットも実装されています。

これは DVD-Video ディスク構造を作る機能ではありません。

### 音声変換系プリセット

- `Audio MP4 AAC Only - High (256 kbps)`
- `MP3 - High (320 kbps)`
- `MP3 - Medium (192 kbps)`
- `M4A AAC - High (256 kbps)`
- 追加の音声プリセット: MP4 AAC、MP3、M4A AAC、WAV PCM、FLAC、OGG Vorbis、WMA

`Car Navi MP4` と `DVD Player MPG` は実用的な変換候補ですが、すべてのカーナビや DVD プレーヤーでの再生を保証するものではありません。実際の再生可否は対象機器の仕様に依存します。

## 9. 注意事項・制限事項

### 著作権・利用規約

ユーザーは、著作権法、各動画サービスの利用規約、権利者の許諾条件を守る責任があります。NaviMovie-Maker は、権利のないコンテンツの保存、変換、再配布を推奨するものではありません。

### 再生互換性は機器に依存

変換後ファイルの再生可否は、対象機器の対応コーデック、解像度、ビットレート、ファイルサイズ制限、ストレージ形式、ファームウェア、再生アプリに依存します。

`Car Navi MP4` や `DVD Player MPG` は実用プリセットであり、すべての機器で再生できる保証ではありません。短いファイルで確認してからまとめて処理することを推奨します。

### yt-dlp / FFmpeg は外部ツール

`yt-dlp`、`FFmpeg`、`ffprobe` は外部ツールです。NaviMovie-Maker は検出、自動取得、設定のサポートを提供しますが、各ツールの対応状況、ライセンス、仕様変更はそれぞれのプロジェクトに依存します。

その他の制限:

- ダウンロード可否は `yt-dlp` と対象サイトに依存します。
- フォルダのドラッグ＆ドロップは再帰読み込みしません。
- チャンネルやプレイリストなど広い URL は通常の URL ドロップでは対象外になる場合があります。
- SD カードや USB メモリ上の物理的な再生順制御は NaviMovie-Maker 本体の機能ではありません。
