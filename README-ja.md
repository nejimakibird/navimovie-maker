# NaviMovie-Maker

## 1. NaviMovie-Maker とは

NaviMovie-Maker は、オンライン動画 URL やローカルの動画・音声ファイルを、カーナビ、USB/SD 対応 DVD プレーヤー、iPad / タブレット、Android タブレット、ローカル再生環境で扱いやすい形式へ準備するための Windows デスクトップアプリです。

現在のアプリは `Conversion Queue` を中心にしたワークフローです。URL やローカルファイルをキューへ追加し、必要に応じて `Simple Mode` または通常モードで処理します。

オンライン動画の取得には `yt-dlp`、変換や音声処理には `FFmpeg` / `ffprobe` を使用します。NaviMovie-Maker には外部ツールの確認・自動取得サポートがありますが、これらのツール自体は NaviMovie-Maker とは別の外部ツールです。

## 2. 主な機能

- `Simple Mode`: URL やローカルファイルをドロップするだけで、選択したプリセットへ変換
- 通常モード: `ダウンロードのみ`、`ダウンロードして変換`、`変換のみ`、`ファイルコピー`
- 検索語から YouTube の動画候補を取得
- 動画 URL を直接入力して候補を取得
- URL を入力欄または `Conversion Queue` へドラッグ＆ドロップ
- ローカル動画・音声ファイルをファイル選択またはドラッグ＆ドロップでキューへ追加
- `Car Navi MP4`、`DVD Player MPG`、iPad / タブレット、Android タブレット、音声変換系プリセットによる変換
- キュー行の状態・進捗表示、全体進捗表示、ログ表示
- 音声補正、音量持ち上げ、連番開始、`DL元を残す`
- 外部ツール確認、自動取得、手動パス指定、`tools` フォルダ表示

## 3. シンプルモード

シンプルモードは、URL やローカルファイルをドロップするだけで、選択したプリセットに変換するための簡易モードです。URL は一時的にダウンロードしてから変換し、ローカルファイルは直接変換します。変換結果は `変換済みフォルダ` に保存され、シンプルモードでは一時ファイルやキャッシュを残さない方針です。

シンプルモードで主に選ぶのは `出力形式` プリセットです。通常モードの `ダウンロードのみ` / `ダウンロードして変換` / `変換のみ` / `ファイルコピー` のような細かいモード選択は表示しません。

シンプルモード中も、項目は `Conversion Queue` に表示されます。変換中はキューの状態列、上部の進捗表示、ログで進捗を確認できます。中断したい場合は、Simple Mode パネルの `キャンセル` ボタンを使用してください。

## 4. 通常モード

通常モードでは、キューに追加した項目を選択した動作モードで上から順番に処理します。Simple Mode を無効にすると、通常モード用の操作パネルが表示されます。

| 画面ラベル | 内部モード | URL | ローカルファイル | 主な用途 |
|---|---|---:|---:|---|
| ダウンロードのみ | `Download Only` | 対象 | 対象外 | URL から元ファイルを取得 |
| ダウンロードして変換 | `Download & Convert` | 対象 | 対象 | URL から取得して指定形式へ変換。対応ローカルファイルも変換 |
| 変換のみ | `Convert Only` | 対象外 | 対象 | ローカル動画・音声ファイルを変換 |
| ファイルコピー | `Copy Files` | 対象外 | 対象 | ファイルを指定フォルダへコピー |

選択中の動作モードで処理できない項目は、キュー上で `対象外` として表示されます。

## 5. URL とローカルファイルの追加

### URL

HTTP / HTTPS の URL は、動画ソース入力欄または `Conversion Queue` へドラッグできます。キューへ URL をドロップすると、項目はすぐに表示され、`yt-dlp` による動画情報取得が始まります。

情報取得中はタイトルが `読み込み中...`、状態が `情報取得中...` になります。取得に成功すると動画タイトルに更新され、出力ファイル名にもそのタイトルが使われます。取得に失敗した場合でも、フォールバックタイトル付きでキューに残り、`注意` として表示されます。

YouTube の単体動画 URL、`youtu.be/...`、Shorts URL は単体動画として扱います。`watch?v=...&list=...` のような URL は、動画 ID がある場合は単体動画 URL に正規化します。チャンネル、プレイリスト、handle、radio など大量展開される可能性がある URL は、通常モードでは拒否または対象外になります。

### ローカルファイル

ローカルの動画・音声ファイルは `Conversion Queue` へドラッグ＆ドロップできます。ファイル選択ボタンから追加することもできます。

対応しているローカルファイル拡張子は次の通りです。

- 動画: `.mp4`, `.m4v`, `.mov`, `.avi`, `.mpg`, `.mpeg`, `.wmv`, `.mkv`, `.webm`
- 音声: `.wav`, `.mp3`, `.m4a`, `.aac`, `.flac`, `.ogg`, `.wma`

フォルダ、存在しないパス、未対応拡張子は、理由を確認できるように `対象外` のキュー項目として表示されます。現在のバージョンでは、フォルダの中身を再帰的には読み込みません。

## 6. キューの状態と進捗

`Conversion Queue` の `状態` 列には、状態テキストと進捗バーが表示されます。変換中の項目では、進捗率、変換済み時間 / 総時間、処理速度、残り時間の目安を表示します。長い動画や 4K 動画など、変換に時間がかかる場合でも処理が進んでいることを確認できます。

主な状態:

- `情報取得中...`: URL ドロップ後、yt-dlp で動画情報を取得中
- `待機中`: 処理開始待ち
- `処理中` / `ダウンロード中` / `変換中`: ダウンロード、変換、コピーなどを実行中
- `対象外`: 現在の動作モードでは処理できない項目、未対応ファイル、広すぎる URL など
- `注意`: メタデータ取得失敗など、処理可能だが確認が必要な項目
- `完了`: 処理が正常に終わった状態
- `失敗`: ダウンロード、変換、コピーに失敗した状態
- `Skipped`: キャンセル、モード不一致、前段失敗などによりスキップされた状態

上部の ProgressBar と進捗テキストには、完了件数だけでなく、実行中項目の途中進捗も反映されます。

## 7. キャンセルと削除

処理中の項目は、変換やダウンロードの進捗表示と内部処理を一致させるため、リストから削除できないようにしています。処理を止める場合は `キャンセル` ボタンを使用してください。

処理中、情報取得中、ダウンロード中、変換中、キャンセル中の項目は、削除ボタンや Delete キーでも削除されません。`待機中`、`対象外`、`注意`、`完了`、`失敗`、キャンセル後に非アクティブになった項目は削除できます。

処理中は、キュー項目の移動やドラッグによる並べ替えも制限される場合があります。

## 8. 音声補正

`音声補正` 列には、キュー項目に適用される音声補正設定を表示します。通常モードでは、選択中のキュー項目に音量ノーマライズなどの音声補正を設定できます。

`音量持ち上げ` は、音量ピークが低いファイルだけを目標ピークまで持ち上げるための機能です。すでに大きい音源を下げるための厳密なラウドネス調整ではありません。事前解析による高度な音量ゲイン調整は今後の検討対象です。

## 9. 出力プリセット

表示する `出力形式` は `設定` の `出力形式` タブで変更できます。Simple Mode でも通常モードと同じプリセット一覧を使用します。

### Car Navi MP4

- `Car Navi MP4 - Current Compatibility`
- `Car Navi MP4 - Standard`
- `Car Navi MP4 - Small Size`
- `Car Navi MP4 - High Quality`

カーナビ向けの実用的な MP4 / H.264 / AAC 系プリセットです。すべてのカーナビでの再生を保証するものではありません。

### DVD Player MPG

- `Portable DVD Player MPG - Small Size (MP2 audio)`
- `Portable DVD Player MPG - Standard (MP2 audio)`
- `Portable DVD Player MPG - High Quality (MP2 audio)`

USB/SD 再生対応 DVD プレーヤー向けの `.mpg` ファイルを作る実用プリセットです。DVD-Video ディスク構造を作る機能ではありません。

### iPad / タブレット

- `iPad / タブレット MP4 1080p 標準`: 現行または一般的なタブレット向けの H.264 MP4
- `iPad / タブレット MP4 720p 互換`: 古めの機器や容量を抑えたい場合向けの H.264 MP4
- `iPad / タブレット HEVC 1080p 高圧縮`: 新しめの機器向け。ファイルサイズを抑えやすい HEVC MP4

### Android タブレット

- `Androidタブレット MP4 1080p 標準`: 現行または一般的な Android タブレット向けの H.264 MP4
- `Androidタブレット MP4 720p 互換`: 古めの機器や容量を抑えたい場合向けの H.264 MP4
- `Androidタブレット HEVC 1080p 高圧縮`: 新しめの機器向け。ファイルサイズを抑えやすい HEVC MP4

H.264 MP4 プリセットは互換性を優先する場合の安全寄りの選択です。HEVC プリセットは高圧縮で便利ですが、古い機器や再生アプリでは再生できない場合があります。

### 音声変換系プリセット

MP4 AAC、MP3、M4A AAC、WAV PCM、FLAC、OGG Vorbis、WMA などの音声出力プリセットがあります。音声のみのファイル作成や音声形式の変換に使用できます。

## 10. フォルダと出力先

既定では、ユーザーの Videos フォルダ配下に `NaviMovie-Maker` 用のフォルダを作ります。

- `作業フォルダ`: `Videos\NaviMovie-Maker\work`
- `一時フォルダ`: `Videos\NaviMovie-Maker\temp`
- `変換済みフォルダ`: `Videos\NaviMovie-Maker\converted`
- `ローカル動画フォルダ`: `Videos\NaviMovie-Maker\local`

`設定` の `フォルダ` タブで各フォルダを変更できます。`出力形式ごとにサブフォルダを作成` が有効な場合、プリセットやモードに応じたサブフォルダへ出力します。

Simple Mode の変換結果は `変換済みフォルダ` に保存されます。通常モードでは、メイン画面の `出力先...` から、そのセッションだけの出力先も選べます。

## 11. 外部ツールと導入サポート

NaviMovie-Maker は次の外部ツールを使用します。

- `yt-dlp.exe`: URL のメタデータ取得とダウンロード
- `ffmpeg.exe`: 動画・音声変換、音声処理
- `ffprobe.exe`: FFmpeg 関連の確認やメディア情報取得

メニューの `ツール` から外部ツールを扱えます。

- `外部ツール確認`: 設定済みパス、アプリの `tools` フォルダ、`PATH` の順に確認
- `外部ツールを自動取得`: `yt-dlp.exe` と FFmpeg essentials zip を取得し、`tools` フォルダへ配置
- `tools フォルダを開く`: アプリが外部ツールを置くフォルダを開く
- `設定`: 外部ツールの実行ファイルパスや取得 URL を手動指定

ダウンロード可否は `yt-dlp` と対象サイト側の状態に依存します。サイト側の仕様変更、利用規約、地域制限、ログイン要否などにより取得できない場合があります。

## 12. 注意事項・制限事項

- ユーザーは、著作権法、各動画サービスの利用規約、権利者の許諾条件を守る責任があります。
- NaviMovie-Maker は、権利のないコンテンツの保存、変換、再配布を推奨するものではありません。
- 変換後ファイルの再生可否は、対象機器の対応コーデック、解像度、ビットレート、ファイルサイズ制限、ストレージ形式、ファームウェア、再生アプリに依存します。
- プリセットは実用的な出力候補であり、すべての機器での再生を保証するものではありません。
- HEVC は高圧縮ですが、H.264 より対応機器が限られます。
- `yt-dlp`、`FFmpeg`、`ffprobe` は外部ツールです。各ツールの対応状況、ライセンス、仕様変更はそれぞれのプロジェクトに依存します。
- フォルダのドラッグ＆ドロップは再帰読み込みしません。
- プレイリスト一括 DL やチャンネル全件 DL は現在の通常モードでは扱いません。
- ハードウェア GPU エンコードは標準機能としては扱っていません。
- SD カードや USB メモリ上の物理的な再生順制御は NaviMovie-Maker 本体の機能ではありません。
